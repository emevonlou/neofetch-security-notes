# Contributing

Thank you for your interest in improving this project.

## Goals

This repository focuses on **defensive tooling and awareness around system metadata exposure**.

Contributions should aim to:

- improve metadata sanitization
- enhance detection of sensitive patterns
- improve documentation clarity
- strengthen security-by-design principles

## Guidelines

Before submitting a change:

1. Ensure no sensitive information is included in commits.
2. Keep tools simple and auditable.
3. Prefer defensive and educational improvements.

## Pull Requests

Please include:

- a clear explanation of the change
- examples or test cases if applicable
- updates to documentation if needed

Security-related contributions are especially welcome.
