# Security Policy

## Reporting Issues

If you discover a security issue related to metadata exposure or sanitization behavior, please report it responsibly.

Open a GitHub issue describing:

- the observed behavior
- why it may lead to unintended metadata disclosure
- possible mitigation

Do not include sensitive data in the report.

## Scope

This project focuses on:

- reducing accidental metadata disclosure
- improving safe sharing practices for system diagnostics
- providing defensive tooling

It does **not perform active reconnaissance or data collection**.

## Responsible Disclosure

Please allow time for review before publicly disclosing security issues.
